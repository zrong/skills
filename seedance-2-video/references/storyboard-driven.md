# 分镜板驱动

用于多宫格分镜、漫画页、连续关键帧或镜头草图。

## 1. 先识别分镜

按阅读顺序记录每格：

- 主体与动作；
- 景别和机位；
- 场景是否连续；
- 角色外观是否一致；
- 格间发生了什么变化；
- 是否存在编号、气泡、边框或说明文字。

只把可见内容当事实；无法辨认的格子要明确标注不确定。

## 2. 选择生成方式

### D1：单条时间轴

适合格数少、同一角色和场景连续、总时长在单次模型限制内的分镜。

将格子转换成时间段：

> 参考 `@图像1` 的分镜内容，但不复刻网格边框、格子编号和分隔线。0—T1 秒：[第 1 格的全屏镜头与动作]；T1—T2 秒：[第 2 格及过渡]；T2—结束：[最后一格和收束]。

### D2：逐镜头生成

适合格数多、跨场景、跨时间、风格变化大或单条时长不足的分镜。

每格或相邻连续格生成一个独立镜头：

```markdown
镜头 N
- 参考：@图像1 第 N 格
- 进入状态：...
- 核心动作：...
- 运镜：...
- 结束状态：...
- 与下一镜头衔接：动作 / 视线 / 构图 / 光线
```

## 3. 连贯性锁定

- 角色：服装、发型、体型、道具位置。
- 场景：主光方向、色调、时间、空间轴线。
- 动作：上一镜头结束姿态等于下一镜头进入姿态。
- 视线：保持人物面对方向，除非明确越轴。
- 镜头：同一段落使用一致的焦段和稳定方式。

## 4. 不能直接照搬的元素

- 分镜格边框、编号、箭头和文字注释；
- 漫画气泡和对白框；
- 各格之间不一致的比例和裁切；
- 仅用于导演说明、并非画面内容的符号。

输出时同时给出生成拆分和剪辑顺序，不能把超出单次时长的分镜硬塞进一条提示词。
