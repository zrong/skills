# 图片驱动视频

用于用户引用一张或多张图片，希望将其变成视频、作为角色或场景参考、抵达目标尾帧，或修正构图比例的场景。

## 1. 先判定图片职责

每张图片只分配一种主要职责：

- **首帧**：视频从该构图和状态开始。
- **角色或产品参考**：锁定外貌、服装、形状和材质，不要求第一帧复刻构图。
- **场景参考**：锁定空间、色调和环境元素。
- **目标关键帧或尾帧**：视频在指定时间演化到该状态。
- **风格参考**：只参考色调、材质或摄影语言。
- **分镜板**：转到 `storyboard-driven.md`，不要把网格直接当单幅首帧。

## 2. 分析图片

记录观察事实：

- 主体数量、位置、朝向和遮挡；
- 景别、视角、画幅和留白；
- 可运动部位与潜在动作方向；
- 光源、色调、材质和环境层次；
- 文字、Logo、水印、真人面部或复杂手部等风险；
- 图片不能证明的内容，不写成既定事实。

## 3. 极简补充原则

图片已经表达清楚的内容不要重复描写。文字主要补充：

1. 图片中没有的时间、动作和运镜；
2. 需要强化的节奏、情绪和关键瞬间；
3. 不希望复刻的网格、文字、水印或边框；
4. 必须保持的主体、产品结构或构图锚点。

## 4. 模板

### 首帧驱动

> `@图像1` 为首帧，保持主体外貌、服装、构图和光线方向一致。起始时 [微动作]，镜头以 [主运动] 跟随 [核心动作]，环境发生 [单一变化]，最终停在 [结束状态]。

### 参考图驱动

> 参考 `@图像1` 的主体外貌与服装、`@图像2` 的场景布局和色调，但不强制复刻任一图片构图。镜头从 [起始景别] 开始，[动作与运镜]，最终 [结束状态]。

### 目标帧驱动

> 视频从 [起始状态] 开始，在第 [schema 允许范围内的时间点] 逐渐演化为 `@图像1` 所示状态；变化过程保持 [主体或场景锚点] 连续，最终稳定停留。

## 5. 风险处理

- 比例不匹配：先提供扩图或重构图提示词，再用生成后的图做参考；不要假装已经扩图。
- 图中有网格：明确“不复刻边框、分隔线、编号和拼贴结构”。
- 图中文字重要：说明是否必须保持；不能可靠保持时提前提示风险。
- 多张图风格差异过大：先统一色调、角色和场景锚点，或拆成多段生成。
- 复杂反应和多人动作：用分节拍描述，避免只写“自然互动”。
