# 长视频生产流水线

用于超过单次生成上限、需要角色一致性或包含多个镜头的项目。

## 1. 前期资产

在生成视频前准备：

- 角色卡：正面、侧面、关键服装和道具；
- 场景锚点：主空间、光线和色调；
- 镜头表：镜头目标、时长、景别、动作和衔接；
- 必要的首帧或关键帧图；
- 统一的命名和 `@图像N` / `@视频N` 素材职责。

图片生成提示词见 `image-generation.md`，分镜板见 `storyboard-driven.md`。

## 2. 镜头表

每个镜头至少包含：

| 字段 | 说明 |
|---|---|
| 目的 | 这个镜头推进什么信息或情绪 |
| 时长 | 必须在所选模型 schema 内 |
| 进入状态 | 主体位置、姿态、环境和光线 |
| 核心动作 | 只保留一个主要视觉事件 |
| 运镜 | 起始构图、主运动、结束构图 |
| 结束状态 | 下一镜头能够接续的锚点 |
| 参考素材 | 图像、视频和音频分别承担什么 |

## 3. 一致性策略

- 固定角色参考图，不在每段更换不必要的素材。
- 每段重复少量稳定锚点：服装、道具、主光方向、色调。
- 使用上一段结束画面或视频作为下一段的连续性参考时，明确“接续什么”，不要只写“延长”。
- 跨场景时用动作、遮挡、甩镜、光线或声音建立转场。

## 4. 生成顺序

1. 先试生成最难、最能验证角色和风格的镜头。
2. 锁定可用的角色图、场景图和提示词锚点。
3. 按镜头顺序生成，记录每段采用的模型参数与参考素材。
4. 失败镜头只调整最可能的单一变量：动作复杂度、运镜、参考职责或提示词密度。
5. 最后按 `editing-rhythm.md` 组织剪辑，不在生成阶段过度承担后期节奏。

## 5. 输出

长视频方案必须给出：总时长、镜头数量、逐镜头提示词、参考素材映射、衔接方式、生成顺序和剪辑建议。不得承诺一次调用生成完整长片。
